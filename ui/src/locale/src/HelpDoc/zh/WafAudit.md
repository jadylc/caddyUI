# WAF 审计

## 这是什么

Show 站点启用 **Web 应用防火墙（WAF）** 后，Coraza 会按 OWASP CRS 规则集检查经过该站点的请求。本页面展示 WAF 检测到的全部可疑请求记录。

## 防护模式

- **仅检测（recommended）**：只记录可疑请求，不阻断流量，适合先观察误报情况。
- **拦截模式**：匹配规则集的可疑请求会被直接拒绝（返回 403），同时在审计日志中留痕。

## 如何启用

在站点编辑弹窗 → **安全** 标签页中打开 "WAF 防护"，选择防护模式后保存。

## 页面操作

- **按主机过滤**：在右上角输入框填写域名关键字，表格实时筛选对应站点的记录。
- **查看详情**：点击行尾 "查看详情" 可查看该条记录的完整字段（事务 ID、客户端 IP、命中规则 ID、严重度、动作等）。
